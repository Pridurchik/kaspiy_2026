# Аппаратная часть «Эко-Щит Каспия»

Программная часть написана так, чтобы работать на дешёвом железе: модель на буе — один ONNX-файл
(9 МБ, звук → вероятности + эмбеддинг), на устройстве нужны только `numpy soundfile pyyaml onnxruntime`.
Ниже — эталонная конфигурация для пилота. Цены и энергопотребление — **оценки**, их нужно
проверить на закупке и в полевом тесте.

## Схема

```
  АКУСТИЧЕСКИЙ БУЙ (×3–6 на участок)            СТАНЦИЯ ВОДЫ (×2–4)              КОРДОН / СЕРВЕР
 ┌──────────────────────────────────┐   ┌───────────────────────────┐   ┌─────────────────────────────┐
 │ гидрофон ─┐                      │   │ зонд: T, pH, O₂, EC,      │   │ шлюз LoRaWAN / LTE-роутер   │
 │ микрофон ─┼─ АЦП 16 кГц ─► ПК    │   │ мутность, уровень         │   │ сервер платформы            │
 │ GPS+PPS ──┘   (Raspberry Pi)     │   │ ─► контроллер (ESP32)     │   │  inspector.py: API, БД,     │
 │ ONNX-детектор, кольцевой буфер   │   │ раз в 10 мин              │   │  пеленг, фьюжн, прогноз,    │
 │ 60 с, клип 8 с на алерт          │   │                           │   │  дашборд (браузер/планшет)  │
 │ LoRa (алерт 1 КБ) / LTE (клип)   │──►│ LoRa (40 байт)            │──►│ + AIS-приёмник (опц.)       │
 │ солнце 20–30 Вт + LiFePO4        │   │ солнце 10 Вт + АКБ        │   │ + Sentinel-2 (интернет)     │
 └──────────────────────────────────┘   └───────────────────────────┘   └─────────────────────────────┘
```

## Акустический буй

| Узел | Вариант для пилота | Зачем |
|---|---|---|
| Вычислитель | Raspberry Pi Zero 2 W (или CM4 для запаса) | ONNX-детектор в реальном времени: окно 2 с, шаг 0.5 с |
| Гидрофон | Aquarian H2a или аналог + предусилитель | моторы лодок (подводный шум винта) |
| Микрофон | всепогодный MEMS-микрофон в ветрозащите над водой | выстрелы, бензопила, авиация (в воздухе) |
| АЦП | I²S-кодек 16 бит (2 канала: гидрофон + микрофон) | 16 кГц достаточно: признаки модели до 8 кГц |
| GPS | u-blox M8/M10 с выходом PPS | координаты буя (дрейф) и **время с точностью ~1 мкс** — без этого не будет пеленга |
| Связь | LoRaWAN 868 МГц до кордона (5–15 км над водой) + LTE-модем где есть покрытие | алерт 1 КБ — по LoRa; клип 8 с (Opus ~16 КБ) — по LTE или по запросу |
| Питание | солнечная панель 20–30 Вт, LiFePO4 12 В 12 А·ч | см. энергобюджет |
| Корпус | шест-буй (spar) IP68, якорь, светоотражатель | устойчив к волне, малозаметен |

**Энергобюджет (оценка):** Pi Zero 2 W с непрерывным инференсом ~1.0 Вт, GPS ~0.1 Вт, кодек и
связь ~0.2 Вт → ~1.3 Вт × 24 ч ≈ 31 Вт·ч/сутки. Аккумулятор 144 Вт·ч — ~4.5 суток без солнца;
панель 20 Вт при 4–5 солнечных часах (Астрахань, весна–лето) даёт 60–80 Вт·ч/сутки — с запасом.
Для экономии: дешёвый детектор энергии будит нейросеть только при звуке выше фона.

**Синхронизация времени:** gpsd + chrony с PPS: системные часы буя совпадают с GPS до микросекунд.
Буй ставит в алерт GPS-время первого отсчёта клипа (`clip_start_ts`), сервер по клипам трёх буёв
строит общий таймлайн и считает разности времён прихода (`localize.py`).

**Защита буя:** GPS-геозона — если буй сместился дальше якорной стоянки, уходит алерт «буй сорван
или украден»; пропадание связи и низкий заряд видны на дашборде (вкладка «Буи и данные»).

## Станция качества воды

| Узел | Бюджетный вариант | Профессиональный вариант |
|---|---|---|
| Зонд | наборы Atlas Scientific (pH, O₂, EC, T) + оптический датчик мутности | многопараметрический зонд YSI EXO / Hydrolab |
| Уровень | ультразвуковой или гидростатический датчик | то же |
| Контроллер | ESP32 + LoRa-модуль | логгер производителя |
| Обслуживание | калибровка pH/O₂ раз в 2–4 недели, чистка от обрастания | раз в 1–3 месяца (щётки-очистители) |

Детектор (`water.py`) сравнивает показания с тем же часом суток за прошлые дни (у воды суточный
цикл), отличает сброс (несколько параметров сразу, ≥ 30 мин, приходит ниже по течению) от сбоя
датчика (один параметр, выброс или «залипание») — обрастание и разряд батареи дают именно сбои.

## Спутник и AIS

* **Sentinel-2** (ESA Copernicus, бесплатно): 10 м, повтор ~5 суток, только без облаков — мутность и шлейфы
  сбросов (`satellite.py`). Для ночи и облачности — Sentinel-1 (радар): суда и нефтяные плёнки (следующий шаг).
* **AIS:** приёмник на кордоне (RTL-SDR + антенна, дальность 20–40 км) или коммерческий фид. Формат — CSV
  `mmsi, ts, lat, lon, name`. Маломерные суда AIS не обязаны иметь: «нет AIS» = «не опознано», а не «нарушитель».

## Ориентировочная стоимость пилота (участок ~5×5 км)

| Позиция | Кол-во | Оценка за ед. |
|---|---|---|
| Акустический буй (вычислитель, гидрофон, микрофон, GPS, связь, питание, корпус) | 4 | 50–90 тыс. ₽ |
| Станция воды (бюджетный зонд) | 3 | 60–120 тыс. ₽ |
| Шлюз LoRaWAN + LTE-роутер + AIS-приёмник на кордоне | 1 | 40–70 тыс. ₽ |
| Сервер (мини-ПК на кордоне или облако) | 1 | 50–80 тыс. ₽ |

Порядок цифр: **0.6–1.0 млн ₽** на участок — дешевле одного патрульного катера, при этом участок
под наблюдением круглосуточно. Цены ориентировочные (конец 2026 г.), уточнить у поставщиков.

## Ограничения, которые нужно проверить в поле

* Дальность слышимости мотора гидрофоном на мелководье дельты (камыш, ил, течение) — от неё зависит шаг сети буёв.
* Многолучёвость и ветер: точность пеленга в симуляции (3–9 м внутри сети) на реальной воде будет хуже.
* Лёд: на зиму буи снимаются (Северный Каспий замерзает) или ставятся ледостойкие вехи.
* Вандализм и кража: малозаметный корпус, геозона, страховка.
