# Политика обработки данных

«Эко-Щит Каспия» — прототип. Ниже описано, какие данные система обрабатывает,
зачем и как минимизируется риск. Документ носит технический характер и **не
заменяет** юридическую оценку соответствия 152-ФЗ (РФ) и применимому праву
прикаспийских государств; перед пилотом её нужно провести.

## 1. Какие данные обрабатываются

| Данные | Источник | Куда попадают | Срок хранения |
|---|---|---|---|
| Аудио с буя (гидрофон/микрофон) | буй (`edge.py`) | клип-доказательство алерта на сервере; `data/feedback/` при решении инспектора | до удаления оператором |
| Алерты (класс события, уверенность, время, координаты буя) | сервер | SQLite (`data/inspector.db`) | до удаления оператором |
| Показания датчиков воды (T, pH, O₂, мутность, …) | станции | SQLite | до удаления оператором |
| Спутниковые снимки Sentinel-2 | Copernicus | вычисляются шлейфы; снимки не хранятся в системе | — |
| AIS (MMSI, время, координаты, название судна) | внешняя выгрузка | только в памяти на время оценки алерта | не хранится |
| Решения инспектора (статус алерта) | дашборд | SQLite + клип в `data/feedback/` | до удаления оператором |

## 2. Принципы

- **Минимизация.** Наружу (в трансграничные уведомления, `transboundary.py`) уходят
  только квадраты 0.5°, без координат патрулей, аудио и персональных данных.
- **Локальность.** Данные хранятся на сервере оператора (SQLite + файлы), в облако
  ничего не отправляется. Внешние сервисы — только загрузка открытых данных
  (ESC-50, UrbanSound8K, Sentinel-2, AIS-выгрузки).
- **Ничего не отправляется автоматически.** Трансграничные уведомления — черновики,
  отправка только после одобрения диспетчером.
- **Обратная связь для обучения.** Клипы «ложная тревога» / «подтверждено» попадают в
  `data/feedback/` и используются только для дообучения модели; это не персональные данные.

## 3. Персональные данные

Система **не** собирает имена, телефоны, лица, номера судов как персональные данные
инспекторов. MMSI и названия судов из AIS относятся к судам, а не к людям; они
используются только для опознания источника шума в момент алерта и не хранятся.

## 4. Безопасность

- Нет встроенной аутентификации дашборда/API — прототип рассчитан на доверенную сеть.
  **Перед публичным развёртыванием обязательно**: HTTPS, аутентификация инспекторов,
  разграничение ролей, ограничение доступа к `data/`.
- Секретов в репозитории нет (проверено). Контакты сторон в конфиге трансграничного
  протокола — заглушки, их нужно заменить на официальные.

## 5. Права и удаление

Оператор может удалить любые записи из `data/` (SQLite и файлы) — они не реплицируются
и не отправляются наружу. Для запроса на удаление/выгрузку обратитесь к владельцу
развёртывания.
